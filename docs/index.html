Install it - or let your AI install it.

Our favorite way: paste one prompt and your AI does the rest. The prompt below keeps verification and host registration explicit.

Install Programmer-Wander v2.0.0-rc.1 from the official AIWander GitHub prerelease. Detect Windows x64 versus ARM64, verify the ZIP against SHA256SUMS, verify programmer.exe has a valid Joseph Wander Authenticode signature, then show me the exact host config and backup path before registering it. Do not restart any host until I confirm.
Get the binary

Choose the exact signed v2.0.0-rc.1 x64 or ARM64 ZIP and verify it before extraction.

Register your host

programmer.exe install --target claude-desktop - or claude-code, lm-studio, all.

Restart and ask

Restart the host, then ask: What can the programmer server do? The bundled skills teach it everything.
