Alpha support boundary: public issue trackers are the support channel. There is no paid support plan, response-time guarantee, or emergency service.

Site, skills, or hook templates

Use the AIProgrammer issue tracker for this website, the two plugin profiles, skills, manifests, rendering instructions, or inert guard-hook templates.

Binary, installer, or tools

Use the Programmer-Wander issue tracker for release assets, installer behavior, host registration, runtime failures, and MCP tool behavior.

Include enough evidence

  • Release tag, Windows architecture, host name and version, and install route.
  • The exact command or tool call, the exact error text, and the smallest reproduction.
  • Whether the issue occurs with the server alone, one plugin profile, or rendered hooks.
  • Redacted logs only. Remove credentials, private paths, repository secrets, and personal data.

Security-sensitive reports

Do not publish exploit details or secrets in a normal issue. Start from the relevant repository's Security tab and use private reporting if GitHub offers it for that repository.

Supported registration boundary

The current CLI explicitly supports claude-desktop, claude-code, lm-studio, and all. Cowork and other MCP hosts require installer detection or manual host configuration. A generic host claim is not proof of an automated install path.

Manager boundary

Manager is a separate planned paid product, currently Beta - Coming Soon. It has no public checkout or public support channel today, and aiwander.ai is a portfolio page rather than a purchase route. No payment is requested by this site. If a public offer opens, its exact product, price, support, privacy, and uninstall terms need their own verified page.
